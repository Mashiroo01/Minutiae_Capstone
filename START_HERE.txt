⚙️ Minimum Setup Steps:

   1. Update config.php:
      - Set your MySQL credentials
      - Set path to bozorth3 executable

   2. Create database:
      - CREATE DATABASE minutiae;

   3. Initialize tables:
      - Call: http://localhost/Minutiae/backend/criminal_record.php?action=init

   4. Access the system:
      - Applicant: http://localhost/Minutiae/dashboard.html
      - Admin: http://localhost/Minutiae/admin.html
