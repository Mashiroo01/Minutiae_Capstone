Protected Admin Access

Admin Authentication Required

This entry point is reserved for authenticated admin and super admin users only. Sign in first to continue to the protected Minutiae administration page.

Role-based access Only admin and super admin accounts can continue to the protected page.
Restricted biometric data Sensitive fingerprint match information remains protected by session-based access control.
Audited access Authentication actions and downstream admin activity continue into the system audit trail.

Sign In

Use an authorized admin or super admin account to access the protected admin page at `index.html`.

You can stay on this login page even if a previous admin session already exists. Use the administrator credentials configured for this installation.
